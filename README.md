# 希冀平台作业题目导出工具

把 **希冀平台** 上**整份作业的题目**一键导出成 Markdown / CSV，方便复习、整理，或丢给 AI 提问。

- 只抓题目，**不自动作答、不提交**。
- 默认**无头运行**，不弹窗口、不占用桌面。
- 登录态会缓存到本地，登录一次即可反复使用。

提供两种方式：

| 方式 | 位置 | 适合 |
| --- | --- | --- |
| 命令行工具 | [`scrape.mjs`](scrape.mjs)（根目录） | 批量归档所有作业、自动化 |
| 浏览器扩展 | [`cg-exporter/`](cg-exporter/) | 边做作业边抓当前这一份 |

---

## 浏览器扩展

位于 [`cg-exporter/`](cg-exporter/)，Manifest V3，Edge / Chrome 通用。

### 安装（开发者模式加载）

1. 打开扩展管理页：Edge `edge://extensions` / Chrome `chrome://extensions`
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本仓库的 `cg-exporter/` 目录

### 使用

1. 先在浏览器里登录希冀平台，并停留在「我的课程」列表页
2. 点工具栏的扩展图标
3. 选好课程，点「抓取当前页面」
4. 点「复制 Markdown」或「下载 .md / .csv」

扩展会优先请求作业索引页，所以即使你当前停留在某一种题型的页面上，也能抓到**整份作业**。

## 命令行工具

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- 本机已安装 Edge 或 Chrome（默认优先用 Edge）

## 安装

```bash
npm install
```

## 使用

### 0. 配置平台地址（只需一次）

希冀平台在**每个学校用的域名不一样**，所以本工具不写死地址，需要你先告诉它你学校平台的地址。

新建一个 `config.json`：

```json
{
  "origin": "https://你学校的希冀平台域名"
}
```

例如把 `https://cstlab.example.edu.cn` 换成你自己学校平台的真实地址（就是浏览器地址栏里那段）。

不想建文件的话，两种临时写法也行：

```bash
# 环境变量
ORIGIN=https://你学校的希冀平台域名 node scrape.mjs 8717

# 单次参数
node scrape.mjs --origin=https://你学校的希冀平台域名 8717
```

> 登录成功之后，工具会**自动把这个地址记进 `config.json`**，之后就不用再配了。
> `config.json` 已在 `.gitignore` 里，属于你的本地配置。

### 1. 首次登录（只需做一次）

```bash
npm run login
```

会弹出一个浏览器窗口，点「统一认证」完成登录。登录成功后按 Enter 结束，登录态会保存到 `cookies.json`。

> 登录态是会话 Cookie，隔较长时间或服务端重启后可能失效，届时重跑一次 `npm run login` 即可。

### 2. 导出题目（无头）

```bash
node scrape.mjs 8717
```

或一次导出多份作业：

```bash
node scrape.mjs 8690 8717 8720
```

也可以直接粘贴浏览器地址栏的链接（域名换成你自己的）：

```bash
node scrape.mjs "https://你学校的希冀平台域名/assignment/index.jsp?assignID=8717"
```

导出结果（UTF-8）：

- `题目_<作业ID>.md`：按题型分组的 Markdown
- `题目_<作业ID>.csv`：带 BOM 的 CSV，可直接用 Excel 打开

### 3. 批量归档全部作业（推荐，复习前先存下来）

```bash
npm run export-all
```

它会遍历你**所有课程的每一份作业**，把还能访问的题目全部导出，按课程分目录存放：

```
题库/13_数据库系统/题目_8850.md
题库/174_Java及Web开发/题目_8690.md
...
```

- **已存在的作业会跳过**，可以放心反复运行（断点续跑）。
- 已截止 / 未发布的作业会显示 `[空] 无可抓题目…` 并跳过，不会报错。
- 建议在**每次作业开放期间**跑一次（或挂到计划任务里），这样复习时题库已经在本地。

> **为什么必须提前存**：希冀平台对**已截止**的作业会在服务端直接清空题目——索引页只剩空表格，
> 题目页返回空响应（实测 20 字节），且在**所有课程下**都取不到。这种情况下浏览器手动打开也是空的，
> 任何工具都无法导出。详见下文「已截止的作业」。

## 支持的题型

自动识别并导出常见题型，包括：

简答题、编程题、程序片段编程题、单选题、多选题、判断题、填空题、完形填空、SQL 编程题、图片上传题等。

## 可选参数（环境变量）

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `--all` / `ALL=1` | 批量归档所有课程的作业 | 关 |
| `--course <id>` | 指定课程 ID，跳过自动探测 | 自动 |
| `OUT_ROOT` | 批量模式输出根目录 | `题库` |
| `PROBE_ONLY=1` | 跳过索引页，只走直连题目页探测 | 关 |
| `SAVE_IMAGES=0` | 不下载题目图片（默认会存到本地 `图片/`） | 下载 |
| `HEADLESS=0` | 显示浏览器窗口（排查问题时用） | 无头 |
| `ORIGIN` | 平台地址（也可用 `--origin=` 或 `config.json`） | 自动记住 |
| `EDGE_PATH` | 自定义 Edge 路径 | 自动探测 |
| `CHROME_PATH` | 自定义 Chrome 路径 | 自动探测 |
| `CDP` | 已开着调试实例时复用它的地址 | `http://127.0.0.1:9222` |

## 已截止的作业：实测结论

对希冀平台做过完整排查，结论如下（以作业 5470 为例）：

| 尝试 | 结果 |
| --- | --- |
| 作业索引页 `index.jsp?assignID=5470` | 正常打开（41 KB），但**题型表格是空的**，无题目链接 |
| 直连题目页 `briefAnswerList.jsp?proNum=1&assignID=5470` | HTTP 200，**响应体只有 20 字节空白** |
| 换课程（8 门课逐个试） | 全部返回空，题目数 0 |
| 加 `courseID` / `libCenter` / `review` / `mode=view` / `all=1` 等参数 | 无效 |
| 打印 / 导出 / 预览 / 答卷回顾等 10 余个猜测端点 | 全部 404 或空 |
| 成绩查询、课程资料、MOOC 等入口 | 无题目数据 |

**同一门课里仍在开放的作业（如 8690）可以正常导出**，所以这不是工具的问题，而是希冀平台对已关闭
的作业在**服务端**就不再返回题目内容。

可行的三条路：

1. **提前归档**（推荐）：用 `npm run export-all` 在作业还开着的时候把题库存到本地。
2. **让老师开放事后查看**：老师可能可以把已截止作业设为「可查看题目/答案」，开启后本工具立刻就能抓。
3. **浏览器缓存**：如果这份作业你还开着的时候在浏览器里点过，页面可能还在磁盘缓存里，可以尝试找回。

## 工作原理

1. 用 Puppeteer 驱动本机 Edge/Chrome，复用缓存的登录态。
2. 进入作业索引页，收集该作业下所有题目的链接。
3. 逐题打开，按题型解析题干、选项、代码模板与填空位置。
4. 汇总输出 Markdown 与 CSV。

## 隐私

- `cookies.json` 与 `.browser-profile/` 含登录凭证，已在 `.gitignore` 中忽略，**切勿提交**。
- `config.json` 记录你学校平台的地址，属于本地配置，也已忽略。
- 导出的 `题库/` 与 `题目_*.md/csv` 同样已忽略，默认不会进仓库。
